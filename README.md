# Rock Paper Scissors (WinForms)

A simple **Rock Paper Scissors game** built using C# Windows Forms.
The game supports **Player vs Player** and **Player vs Computer** modes with multiple rounds, score tracking, and a results screen.

---

## 🎮 Features

* Player vs Player mode
* Player vs Computer mode
* Multiple rounds selection
* Score tracking (wins, losses, draws)
* Visual round feedback (win/loss colors)
* Restart game option
* Return to main menu

---

## 🧠 Game Flow

```
Main Menu → Game Setup → Game → Results → (Restart / Home)
```

---

## 🛠 Technologies Used

* C#
* Windows Forms (.NET)
* Object-oriented programming
* Event-driven UI design

---

## 📁 Project Structure

* `frmMain` → Main menu (choose game mode)
* `frmGameSetup` → Player names + round settings
* `frmGame` → Core gameplay logic
* `frmResults` → Final results screen
* `GlobalTypes.cs` → Game enums & structs
* `Settings.cs` → Global settings/colors

---

## 📌 Notes

* Designed as a learning project for WinForms UI and game logic
* Focus on clean form navigation and state handling
* AI opponent uses random selection
